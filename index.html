01 About

Production software for plants, operators, and the systems around them.

I build web applications, APIs, and SQL Server systems that operations teams actually run — including Level 2 software for rolling mills, plus the interfaces that connect plant data to MES, SAP, and mill-specific systems.

Before this I worked on HMS (Hospital Management System) platforms and business applications using AngularJS, VB.NET, and ASP.NET MVC. The stack changed; the work did not: understand the process, model the data, ship software people depend on.
