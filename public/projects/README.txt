Project media folders. Create a subfolder named after the project `id` in data/projects.js.

Suggested files per project:
  cover.jpg
  architecture.jpg
  01.jpg, 02.jpg, ...
  demo.mp4 (optional)

Point `cover`, `architectureImage`, `screenshots`, and `video` at these paths in data/projects.js.
If a path is empty, the site shows a placeholder.
